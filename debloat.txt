# Amazon packages Sean's sticks run disabled (pm disable-user: reversible, never uninstalled).
# The one list: `homectl health` checks it, and FireStick-Tune.ps1 (next to this repo) applies it.
# Format: <group> <package> <why>. core = always; extra = only with FireStick-Tune.ps1 -Extras.
# Packages a firmware doesn't have are skipped. Fire OS refuses to disable two, so they're left out:
# com.amazon.device.crashmanager, com.amazon.tv.csapp.
# Deliberately never here: Amazon home (com.amazon.tv.launcher), keyboard, settings, Alexa voice
# (com.amazon.vizzini), Appstore (com.amazon.venezia), system updates, Prime Video.
